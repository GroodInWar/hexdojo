# HexDojo public website

Public visitor interface and module summaries for https://hexdojo.dev. This is a clean, allowlisted source export, not the private production repository or its history.

Run `npm test`, then `python3 -m http.server 8080 --directory public`. Open the local server to browse the homepage, cryptography and network module summaries, Community, and Support pages. Production sign-in/account study resources are unavailable in this static preview.

Account persistence, production orchestration, hosted executors, trusted grading, hidden solutions, deployment manifests, and student data are excluded.
